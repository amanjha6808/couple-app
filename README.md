# 📖 Our Little Book — Handcrafted Couples Scrapbook & Journal

A digital scrapbook that feels like an authentic physical memory book created and shared by two people. Intimate, tactile, whimsical, nostalgic, and freeform.

---

## ✨ Features Built & Delivered

### 1. 📔 Physical Book Experience & Landing Hero
- **Tactile 3D Scrapbook Cover**: Embossed gold foil title, partner dedications (*Aman & Sarah*), cloth spine crease, and bookmark ribbon.
- **Micro-interactions**: Hover depth tilts, subtle ambient floating particles, and smooth book opening transitions.
- **Live Memory Counter**: Displays actual crafted page counts and cherished memories dynamically.

### 2. 📖 Two-Page Physical Spread Canvas
- **Physical Gutter & Spine Depth**: Realistic center binding groove with dual-side ambient drop shadows.
- **Custom Paper Finishes**:
  - *Creamy Canvas* (Warm subtle grid)
  - *Aged Parchment* (Vintage sepia texture)
  - *Soft Blush* (Romantic pink gradient)
  - *Bullet Dot Grid* (Dot journal layout)
  - *Ruled Notebook* (Lined notepad finish)
  - *Heavy Grain Paper* (Tactile physical craft paper)
- **Ribbon Bookmarking**: Toggleable silk bookmark ribbon attached to special pages.

### 3. 🎨 Freeform Scrapbook Engine
- **Touch & Drag Positioning**: Freeform movement across left and right pages without rigid SaaS grids.
- **Micro Action HUD**: Fast 15° rotation, duplicate element, lock/unlock position, and delete.
- **Partner Attribution Badge**: Shows who created or placed each memory (*"Added by Aman"*, *"Added by Sarah"*).
- **Undo / Redo & Autosave**: Full state history stack with quiet *"Saved just now"* feedback and `localStorage` persistence.

### 4. ✂️ Photo → Die-Cut Sticker Studio
- **Custom Photo Upload**: Turn real partner snapshots, pet photos, or memories into vinyl stickers.
- **Contour Silhouette Modes**: Die-cut border, circle badge, and vintage stamp edges.
- **Custom Vinyl Borders**: Slider for border thickness (0–14px), custom border colors, and tactile 3D drop shadow.

### 5. ✒️ Handmade Doodle Studio
- **Drawing Tools**: Ink Pen, Marker Highlighter (semi-transparent stroke), and Eraser.
- **Handmade Stamps**: One-click organic doodles for hand-drawn hearts, stars, squiggles, and sparkles.
- **Transparent Canvas Export**: Instantly places hand-drawn doodles directly onto the page.

### 6. 💌 Wax-Sealed Anniversary Letters
- **Locked Memory Capsules**: Secret love letters sealed with a wax stamp.
- **Timed / Anniversary Unlocks**: Partners can break the seal on their anniversary date, read the personal letter, and reseal it anytime.

### 7. 📸 Polaroids, Washi Tape & Date Rating Cards
- **Polaroid Generator**: Realistic photo paper framing, handwritten captions, and filters (*Golden Warm, Nostalgic Vintage, Black & White Film*).
- **Washi Tape Strips**: Dots, stripes, and kraft tape with adhesive paper styling.
- **Handmade Date Ratings**: Score romance, vibe, drinks, and laughter (1–10) with heart badges.

### 8. ⏳ Visual Relationship Timeline
- Chronological path highlighting first dates, milestone anniversaries, and roadtrips.
- Clicking any timeline card flips the scrapbook directly to that exact memory spread.

### 9. 🖋️ Customized Typography
- Loaded with rich romantic Google fonts:
  - *Playfair Display* & *Cinzel* (Serif headings)
  - *Caveat* & *Dancing Script* (Handwritten notes & captions)
  - *Special Elite* (Vintage typewriter memories)
  - *Lora* (Editorial journal entries)
- Advanced text curvature options (Arch / Curved text).

## 🚀 Running the App Locally

The application is built with React 19, TypeScript, and Vite:

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

Open [http://127.0.0.1:5173/](http://127.0.0.1:5173/) in your web browser.
